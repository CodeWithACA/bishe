# AirSim MAVLink 连接与控制经验文档

## 目标

本目录提供一个可复用的 `pymavlink` 工具，用于：

- 连接 AirSim/ArduPilot 无人机。
- 获取经纬度、高度、水平速度、垂直速度、离起点距离、当前模式、解锁状态、电池、GPS、姿态等信息。
- 发送解锁、起飞、降落、返航、模式切换等命令。
- 用键盘发送速度控制，实现前后、左右、升降、偏航。

默认连接地址是：

```text
udpin:192.168.240.1:18570
```

## 参考项目结论

参考项目 `D:\WorkSpace\works\gcs-latest` 的核心 MAVLink 逻辑在 `DroneWorker.py`：

- 用 `mavutil.mavlink_connection(...)` 建立连接。
- 先发送地面站 `HEARTBEAT`，再 `wait_heartbeat()` 等待飞控心跳。
- 用 `REQUEST_DATA_STREAM` 请求遥测流。
- 主循环中 `recv_match(timeout=1.0)` 接收消息，再按 `msg.get_type()` 分发解析。
- 解锁使用 `MAV_CMD_COMPONENT_ARM_DISARM`。
- 起飞使用 `MAV_CMD_NAV_TAKEOFF`。
- 模式切换使用 `master.set_mode(mode)`。
- 参考项目已有 `MANUAL_CONTROL` 和 `RC_CHANNELS_OVERRIDE` 思路，但主循环中持续发送部分被注释，因此单纯更新摇杆变量不会真正持续控制飞机。

本项目保留这些经验，并补充了三个改进：

- 命令发送后尽量读取 `COMMAND_ACK`，知道飞控是否接受命令。
- 键盘控制采用 `SET_POSITION_TARGET_LOCAL_NED` 的机体系速度指令，在 GUIDED 模式下持续发送，比一次性摇杆变量更适合键盘控制。
- 会根据心跳里的 autopilot 类型区分 ArduPilot 和 PX4/AirSim：ArduPilot 使用 `GUIDED`，PX4/AirSim 使用 `OFFBOARD` 或 `TAKEOFF` 等 PX4 模式名。

- 经纬度：有有效值

- GPS：3D fix，约 15 颗卫星

`POSCTL` 是 PX4 常见模式名，所以这条 AirSim 链路不能只按 ArduPilot 的 `GUIDED` 模式处理。

- `ARM_DISARM` 返回 `MAV_RESULT_TEMPORARILY_REJECTED`。
- `DO_SET_MODE` 返回 `MAV_RESULT_ACCEPTED`。
- `MAV_CMD_NAV_TAKEOFF` 返回 `MAV_RESULT_ACCEPTED`。
- 后续快照显示模式进入 `TAKEOFF`，但 `armed=false`，相对高度仍约 0 m。

结论：命令链路是通的，飞控收到了模式/起飞命令；但当前仿真状态暂时拒绝解锁，所以没有真正离地。下一步应重点查看 PX4/AirSim 的解锁条件、状态文本 `STATUSTEXT`、遥控输入/安全开关/传感器健康状态。

## 建链流程

核心代码：

```python
master = mavutil.mavlink_connection("udpin:192.168.240.1:18570")
master.mav.heartbeat_send(
    mavutil.mavlink.MAV_TYPE_GCS,
    mavutil.mavlink.MAV_AUTOPILOT_INVALID,
    0, 0, 0,
)
master.wait_heartbeat(timeout=30)
```

连接成功后，`master.target_system` 和 `master.target_component` 就是后续命令的目标系统和组件。

## 请求遥测

旧接口：

```python
master.mav.request_data_stream_send(
    master.target_system,
    master.target_component,
    mavutil.mavlink.MAV_DATA_STREAM_ALL,
    20,
    1,
)
```

新接口：

```python
master.mav.command_long_send(
    master.target_system,
    master.target_component,
    mavutil.mavlink.MAV_CMD_SET_MESSAGE_INTERVAL,
    0,
    mavutil.mavlink.MAVLINK_MSG_ID_GLOBAL_POSITION_INT,
    100000,
    0, 0, 0, 0, 0,
)
```

`100000` 表示 100000 微秒一次，也就是 10 Hz。

## 当前已解析的信息

| 信息 | MAVLink 消息 | 字段与换算 |
|---|---|---|
| 经纬度 | `GLOBAL_POSITION_INT` | `lat / 1e7`, `lon / 1e7` |
| 海拔高度 | `GLOBAL_POSITION_INT` | `alt / 1000`，单位米 |
| 相对高度 | `GLOBAL_POSITION_INT` | `relative_alt / 1000`，单位米 |
| 水平速度 | `GLOBAL_POSITION_INT` | `sqrt(vx^2 + vy^2) / 100`，单位 m/s |
| 垂直速度 | `GLOBAL_POSITION_INT` | `-vz / 100`，单位 m/s，向上为正 |
| 本地速度 | `LOCAL_POSITION_NED` | `vx/vy/vz`，单位 m/s |
| 空速/地速/爬升率 | `VFR_HUD` | `airspeed`, `groundspeed`, `climb` |
| 姿态角 | `ATTITUDE` | `roll/pitch/yaw` 从弧度转角度 |
| 模式与解锁状态 | `HEARTBEAT` | `master.flightmode`；`base_mode` 检查 armed 位 |
| 电池 | `SYS_STATUS` | `voltage_battery / 1000`；`current_battery / 100` |
| GPS | `GPS_RAW_INT` | `fix_type`, `satellites_visible` |
| 飞控状态文本 | `STATUSTEXT` | `text`, `severity`，常用于解释拒绝解锁或拒绝模式切换的原因 |
| 离起点距离 | 本地计算 | 首个非零经纬度作为起点，用 Haversine 公式计算 |

## 命令发送

### 解锁

```python
master.mav.command_long_send(
    master.target_system,
    master.target_component,
    mavutil.mavlink.MAV_CMD_COMPONENT_ARM_DISARM,
    0,
    1, 0, 0, 0, 0, 0, 0,
)
```

`param1=1` 解锁，`param1=0` 上锁。

### 起飞

ArduPilot 通常先切到 `GUIDED`，再解锁，再起飞：

```python
master.set_mode("GUIDED")
master.mav.command_long_send(
    master.target_system,
    master.target_component,
    mavutil.mavlink.MAV_CMD_NAV_TAKEOFF,
    0,
    0, 0, 0, 0, 0, 0,
    3,
)
```

最后一个参数是目标高度，单位米。

PX4/AirSim 场景下，模式名通常是 `POSCTL`、`OFFBOARD`、`TAKEOFF`、`LAND`、`RTL`。本工具在 `takeoff` 时会先解锁，再尝试切 `TAKEOFF`，并同时发送 `MAV_CMD_NAV_TAKEOFF`。

### 模式切换

```python
master.set_mode("GUIDED")
master.set_mode("LOITER")
master.set_mode("LAND")
master.set_mode("RTL")
```

ArduPilot Copter 常用模式：

| 模式 | 用途 |
|---|---|
| `STABILIZE` | 自稳 |
| `ALT_HOLD` | 高度保持 |
| `LOITER` | 悬停 |
| `GUIDED` | 外部命令控制 |
| `LAND` | 降落 |
| `RTL` | 返航 |
| `POSHOLD` | 定点 |
| `BRAKE` | 刹停 |

PX4/AirSim 常用模式：

| 模式 | 用途 |
|---|---|
| `POSCTL` | 位置控制 |
| `ALTCTL` | 高度控制 |
| `OFFBOARD` | 外部程序控制 |
| `TAKEOFF` | 自动起飞 |
| `LAND` | 降落 |
| `RTL` | 返航 |

## 键盘控制原理

键盘控制发送 `SET_POSITION_TARGET_LOCAL_NED`，坐标系用 `MAV_FRAME_BODY_NED`：

- `vx`：机头方向速度，正数前进。
- `vy`：机体右侧速度，正数右移。
- `vz`：NED 坐标的 Down 方向速度，正数下降，负数上升。
- `yaw_rate`：偏航角速度，弧度每秒。

代码中忽略位置、加速度和绝对 yaw，只使用速度和 yaw rate。

关键点：

- 控制前切到速度控制模式。ArduPilot 是 `GUIDED`，PX4/AirSim 是 `OFFBOARD`。
- PX4 进入 `OFFBOARD` 前需要先收到一段连续 setpoint，所以脚本会先发约 1 秒 0 速度，再切 `OFFBOARD`。
- 指令需要持续发送，建议 5-20 Hz。
- 键盘释放后要自动发送 0 速度，避免无人机继续运动。
- 速度先用小值，比如 0.3-1.0 m/s。

## 未来读取其他信息怎么做

步骤固定：

1. 在 MAVLink Common Message Set 中找到需要的消息，例如 `BATTERY_STATUS`、`EKF_STATUS_REPORT`、`HOME_POSITION`、`RANGEFINDER`、`DISTANCE_SENSOR`。
2. 在 `_request_telemetry_streams()` 中用 `MAV_CMD_SET_MESSAGE_INTERVAL` 请求该消息频率。
3. 在 `update_telemetry()` 中添加一个 `elif msg_type == "消息名"` 分支。
4. 按官方单位做换算，例如 mm 转 m、cA 转 A、degE7 转度。
5. 把字段加到 `Telemetry` 数据类里，这样 `monitor --json` 会自动输出。

示例：读取测距传感器。

```python
elif msg_type == "DISTANCE_SENSOR":
    telemetry.range_m = msg.current_distance / 100.0
```

同时请求：

```python
mavutil.mavlink.MAVLINK_MSG_ID_DISTANCE_SENSOR: 10
```

## 未来实现其他功能怎么做

### 去某个经纬度

使用 `SET_POSITION_TARGET_GLOBAL_INT` 或任务航点。更推荐在 GUIDED 模式下发送目标位置：

- `lat_int = int(latitude * 1e7)`
- `lon_int = int(longitude * 1e7)`
- `alt` 单位米

### 本地速度控制

当前键盘控制已经是本地速度控制。要接入手柄或 UI，只要把摇杆映射成：

```text
forward_m_s, right_m_s, down_m_s, yaw_rate_rad_s
```

然后周期调用 `send_body_velocity(...)`。

### RC 通道覆盖

如果飞控配置依赖 RC 通道，可用：

```python
master.mav.rc_channels_override_send(
    master.target_system,
    master.target_component,
    ch1, ch2, ch3, ch4,
    65535, 65535, 65535, 65535,
)
```

`65535` 表示不覆盖该通道。RC 覆盖适合兼容传统飞控输入，但对自动控制程序来说，速度/位置目标通常更清晰。

### 等待命令结果

发 `COMMAND_LONG` 后读取 `COMMAND_ACK`：

```python
msg = master.recv_match(type="COMMAND_ACK", blocking=True, timeout=3)
```

常见结果：

- `MAV_RESULT_ACCEPTED`：接受。
- `MAV_RESULT_DENIED`：拒绝。
- `MAV_RESULT_UNSUPPORTED`：不支持。
- `MAV_RESULT_TEMPORARILY_REJECTED`：暂时拒绝，可能模式或状态不满足。

## 安全注意事项

- 在仿真里先测试，确认 AirSim 和飞控参数允许 GUIDED 控制。
- 起飞前确认模式、解锁状态、高度、GPS 或本地定位正常。
- 键盘控制默认短脉冲，松开后会停。不要改成无限保持速度，除非有明确的急停逻辑。
- `disarm --force` 只用于确认安全的场景。
- 模式切换和起飞可能被飞控拒绝，一定要看 `COMMAND_ACK` 和后续 `HEARTBEAT` 的模式回传。

## 常见问题

### 一直等不到 heartbeat

- 确认 AirSim/ArduPilot 已启动。
- 确认端口和方向。`udpin:192.168.240.1:18570` 表示本程序在该地址端口等待 UDP 包。
- 如果本机监听所有网卡更合适，试：

```powershell
python .\mavlink_bridge.py --connect udpin:0.0.0.0:18570 monitor
```

### 能看到遥测但不能起飞

- 先切 `GUIDED`。
- 检查是否已解锁。
- 看 `COMMAND_ACK` 是否是 `ACCEPTED`。
- 检查 AirSim/ArduPilot 的安全检查、GPS、EKF、地理围栏等限制。

### 键盘控制没反应

- 确认当前模式是 `GUIDED`。
- 确认无人机已起飞。
- 降低速度值先测试，例如 `--speed 0.3`。
- 有些固件配置不接受机体系速度，可改成 `MAV_FRAME_LOCAL_NED` 并用世界坐标速度。
